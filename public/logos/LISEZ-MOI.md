# Logos des maisons partenaires

Les 11 logos sont déjà en place (provisoires, voir `SOURCES.md` pour leur origine et la réserve sur les droits). Pour en remplacer un par la version officielle d'une maison, déposez ici un fichier, nommé exactement comme ci-dessous. Format accepté : `.svg` (idéal), `.png`, `.webp` ou `.jpg`.
Tant qu'un logo manque, le nom de la maison s'affiche à sa place dans le défilé : rien ne casse.

| Baronne | `baronne` |
| Girafe | `girafe` |

| Thoumieux | `thoumieux` |
| Maxim's | `maxims` |

Conseils pour un rendu soigné :

- **Fond transparent** obligatoire (SVG ou PNG détouré). Un logo sur fond blanc ferait un rectangle.
- Le site passe tous les logos en **ivoire monochrome**, pour qu'ils restent homogènes avec la charte : fournir la version noire ou blanche unie suffit, les couleurs d'origine ne sont pas utilisées.
- Largeur d'au moins 400 px pour un PNG ; prévoir de la marge minimale autour du logo.
- Utiliser les logos officiels fournis par les maisons, avec leur accord.
